# **App Name**: IDUNI Web

## Core Features:

- About Us: Display information about the church's mission, vision, and beliefs.
- Founder's Info: Show information about the founder or leaders of the church.
- Bible Studies: A tool to create AI generated quizzes to allow the user to create comprehension assessments from bible study text.
- New Moons and Holy Days: Display a schedule or information about the New Moons celebrations and holy days observed by the church.
- Ten Commandments: Display the Ten Commandments.
- Sanctuaries List: Show the list of sanctuaries.
- Contact Information: Contact Information for each of the locations.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to convey reverence and spirituality.
- Background color: Very light lavender (#F0F2FA) for a calm, welcoming atmosphere.
- Accent color: Soft gold (#BDB18B) for highlights, calls to action, and important details.
- Headline font: 'Playfair', serif, for titles and important texts.
- Body font: 'PT Sans', sans-serif, to create easily readable sections.
- Use simple, elegant icons related to faith, community, and worship.
- Clean, spacious layout with clear sections for each content type, in the style of Hillsong's website.
